# Trouver de l'aide

- `man ls` : la page de manuel complète. Dans le pager, flèches et espace pour défiler, `/mot` pour chercher, **q pour quitter**.
- `ls --help` : l'aide courte, directement dans le terminal.
- `apropos copie` (ou `man -k copie`) : cherche un mot dans le résumé de toutes les commandes - quand on ne connaît pas le nom.
- `whatis cp` : le résumé d'une ligne.
- `type cd` : dit si c'est une commande interne du shell ou un programme.

**À retenir** : lire le manuel n'est pas une perte de temps, c'est le métier. Les options d'une commande y sont toutes.
